API Key Settings

SkyPulse queries the OpenWeatherMap REST API directly. Enter your personal API key below to enable live searches. The key is securely stored in your browser's localStorage.

How to get your free API key:

  1. Create an account at openweathermap.org.
  2. Go to the API keys tab in your profile.
  3. Copy your default 32-character key and paste it above.
  4. Note: Brand new keys can take 10 to 60 minutes to activate on OpenWeatherMap's servers.
